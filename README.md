# Dario.Portfolio

Personal portfolio website of Dario Martinez, a full stack developer. This repository contains the source code of an interactive single-page application that showcases my profile, projects and contact information.

## Topic / Description

The site is a modern portfolio built around a **neon violet/glow visual language**, featuring:

- **Responsive single-page layout** with sections for Home, About, Projects and Contact.
- **Project cards** with hover glow effects and a detail modal.
- **Internationalization** (Spanish / English) through custom translation files and a language context.
- Built with **React + TypeScript + Vite** and **Tailwind CSS v4**.
